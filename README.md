# Freej | فريج — website design preview

Static, phone-friendly preview of the Freej marketplace design (V3 — brand kit). Sample listings, people and messages; photos are placeholders. Not connected to Sharetribe yet — forms and chat don't send.

Hosted with GitHub Pages (Settings → Pages → Deploy from branch → main / root). Search engines are blocked on purpose (robots.txt + noindex) while this is a preview.
